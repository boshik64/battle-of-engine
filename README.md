# Битва моторов

Промостраница фильма: scroll-постер, выбор попутчика, свой результат и результат друга.

Исходники лежат в папке `Битва моторов` (кадры, логотип, шрифт Angst, кадры скролла). В страницу они скопированы в `public/` и `fonts/`.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на [http://127.0.0.1:47231](http://127.0.0.1:47231).

Голоса пишутся в `data/votes.json` (анонимная cookie `bm_sid`). События шаринга — в `data/events.jsonl`. Счётчик Метрики подключается переменной `NEXT_PUBLIC_METRIKA_ID`, публичный адрес для OG — `NEXT_PUBLIC_SITE_URL`.

Проверка правил голоса и форм «поездка / поездки / поездок»:

```bash
npm test
```
